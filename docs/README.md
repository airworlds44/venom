# Venom documentation site

This directory is a plain static site so it can be served by GitHub Pages or any static host without a build step.

- `index.html` is the project landing page.
- `demo-report.html` is a clearly labeled synthetic example of Venom's HTML report output.

## GitHub Pages

A repository administrator can publish this directory with GitHub Pages by choosing the `main` branch and `/docs` folder as the Pages source in the repository settings. Do not add a `CNAME` file unless a domain is actually owned and configured for this project.

The site itself does not require provider API keys and makes no model calls.
