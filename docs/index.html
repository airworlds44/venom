Open-source • Python • early alpha

Venom

A small, vendor-neutral CLI for running the same prompts across AI providers, recording reproducible results, scoring outputs, tracking token usage and optional costs, and generating shareable HTML reports.

View on GitHub Quick start
Compare models
Run one prompt or a reusable prompt suite across OpenAI and Anthropic model IDs available to your account.
Keep evidence
Save JSONL with responses, latency, token metadata, timestamps, and optional local cost estimates.
Score deterministically
Apply exact, contains, and regex checks without paying for an LLM judge.
Use it in CI
Benchmark mode emits fresh run, score, report, and summary artifacts with useful exit codes.

Try the report flow without an API key

The repository includes a clearly labeled synthetic demo fixture. It is not presented as a live provider benchmark.

git clone https://github.com/airworlds44/venom.git
cd venom
python -m venv .venv
source .venv/bin/activate
pip install -e .
venom report --input examples/demo-runs.jsonl --out demo-report.html

One-command benchmark

venom benchmark \
  --suite examples/prompts.yaml \
  --model openai:YOUR_OPENAI_MODEL \
  --model anthropic:YOUR_CLAUDE_MODEL \
  --rules examples/scorers.yaml \
  --out-dir benchmark-results \
  --fail-on-miss

Venom does not bundle provider prices or API credentials. Pricing is opt-in through a local file, and provider SDKs read your environment variables normally.
